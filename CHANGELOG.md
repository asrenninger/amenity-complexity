## [0.1.0] - 2025-01-08

### Added

- Initial release
- Core complexity computation (`compute_complexity`) with Juhász and Hidalgo methods
- POI extraction from Foursquare Open Source Places (`pois_from_foursquare`)
- POI extraction from Overture Places (`pois_from_overture`)
- Geographic utilities for FUA loading and H3 grid mapping
- Command-line interface (`amenity-complexity`)
- Exploratory notebook demonstrating end-to-end workflow
